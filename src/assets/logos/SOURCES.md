# Logo sources

## Simple Icons 16.35.0 (CC0 1.0)

`swift`, `graphql`, `postgresql`, `spring-boot`, `figma`, `jest` and `xcode`
come from [Simple Icons](https://simpleicons.org), release **16.35.0**
(published 2026-10-11), fetched from the tagged source on GitHub:

    https://raw.githubusercontent.com/simple-icons/simple-icons/16.35.0/icons/<name>.svg

The icons are licensed CC0 1.0 (public domain dedication); see
https://github.com/simple-icons/simple-icons/blob/16.35.0/LICENSE.md.

The only change made to each file is a `fill="#rrggbb"` attribute on the root
`<svg>`, set to the brand colour listed in Simple Icons' `data/simple-icons.json`
(the originals have no fill). Each file was checked before it was added: only
`<svg>`, `<title>` and `<path>` elements, no scripts, event handlers, links,
styles or embedded images.

Simple Icons has no Java icon in this release (only OpenJDK, a different mark),
so Java is not shown in the carousel.

## Others

The remaining logos here (React, TypeScript, JavaScript, Angular, Tailwind CSS,
HTML, CSS, Python, Git) were added earlier and their original source was not
recorded.
